Правила SenYa
  1. Уважай других пользователей.
  2. Не загружай вирусы и вредоносные файлы.
  3. Публикуй только игры и материалы, на которые у тебя есть права.
  4. Не размещай чужие личные данные.
  5. Не публикуй незаконный или опасный контент.

Демо-режим: профиль сохраняется только в этом браузере. Не используй настоящий или важный пароль. Для публичного запуска нужна защищённая серверная регистрация.

Вход в SenYa

Войди в аккаунт, созданный в этом браузере.

Опубликовать игру

Добавь игру в каталог SenYa. Для публикации сначала войди в аккаунт.

Пока публикация сохраняется только в этом браузере. Файл самой игры на сервер не загружается — для этого понадобится хранилище и backend.
